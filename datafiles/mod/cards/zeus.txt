// 至尊天神（金卡 · 天神·宙斯最终形态）：全屏落雷，5×5 范围伤害
// 按 mod 分支 obj_zeus（shape 3）+ obj_zeus_bullet 移植。
//
//   Create：attack_anim = 30、idle_anim = 11、flash_speed = 5、target_type = "track"
//   Step  ：只要场上有敌人就开打（原版不限行列）。一轮里：
//             at == cycle - 55 / 50 / 45 / 40 / 35 → 各落一道雷（后三个是最终形态多出来的）
//             at > cycle → 归零
//           注意原版**没有** is_frozen 判定，而且「没敌人」时 attack_timer 是**停住不清零**的
//           （只有 else 分支在 at > cycle 时才归零），这里照抄。
//   落点  ：原版取场上最靠左的敌人，算出预判位置
//             predicted_x = 敌人.x - 敌人.move_speed * 30
//           然后在 (predicted_x + 100, 敌人.y - 50) 落雷，等 30 帧后结算：
//             行：|敌人行 - 落点行| <= 2      → 5 行
//             列：|敌人.x - 落点.x| <= 240    → 约 ±2.24 格
//           索敌直接用 VM_GetHomingTarget("")：它返回的就是「最靠左、同 x 血最高」的敌人，
//           跟原版 min_x 那套规则一致。
//   伤害  ：原版是第 30 帧一次性对范围内**所有敌人**（不限类型）各打一次 atk。
//           管理器没有「延迟后打一次」，所以这里用一颗**静止**的子弹表达：
//             生命 30 帧、每帧对范围内所有敌人扣 atk/30 → 全程待在范围内的敌人总量仍是 atk
//             动画 17 帧用 anim_speed = 17/30 ≈ 0.567 拉满 30 帧，落雷动画正好演到结算那一刻
//           类型填 "all"（原版那次范围伤害不看类型，连空中也打）。

_OBJECT_CFG {
    // 统一写内部 spr 名：内置有就直接用；内置没有才把本地图挂到这个名上。
    // 本体：42 帧，原点 (71, 578)
    if (VM_SpriteExists("spr_zeus_3") == 0) {
        VM_LoadSpritePerm_Ex("tex/spr_zeus_3_0.png", 42, 71, 578)
        VM_AliasSpritePerm("spr_zeus_3", "tex/spr_zeus_3_0.png")
    }

    // 落雷：17 帧，原点 (161, 534)
    if (VM_SpriteExists("spr_zeus_bullet") == 0) {
        VM_LoadSpritePerm_Ex("tex/spr_zeus_bullet_0.png", 17, 161, 534)
        VM_AliasSpritePerm("spr_zeus_bullet", "tex/spr_zeus_bullet_0.png")
    }
}

_OBJECT_CREATE {
    self = VM_GetCurCard()

    VM_SetProp(self, "sprite_index", "spr_zeus_3")
    VM_SetProp(self, "idle_anim", 11)
    VM_SetProp(self, "attack_anim", 30)
    VM_SetProp(self, "flash_speed", 5)
    VM_SetProp(self, "plant_type", "normal")
    VM_SetProp(self, "target_type", "track")

    VM_SetProp(self, "attack_timer", 0)
    VM_SetProp(self, "state", 0)
}

_OBJECT_STEP {
    self = VM_GetCurCard()

    cfs = VM_GetProp(self, "flash_speed")
    if (VM_GetProp(self, "is_slowdown") == 1) {
        cfs = cfs * 2
    }

    at = VM_GetProp(self, "attack_timer")
    st = 0
    fire = 0

    // 原版：场上有敌人（is_frozen 不判）
    if (VM_EnemyInRange(0, 99, 0, 99, "all") == 1) {
        cyc = VM_GetProp(self, "cycle")

        if (at <= cyc - 30 * cfs) {
            at = at + 1
        } else if (at == cyc - 55) {
            fire = 1
            at = at + 1
        } else if (at == cyc - 50) {
            fire = 1
            at = at + 1
        } else if (at == cyc - 45) {
            fire = 1
            at = at + 1
        } else if (at == cyc - 40) {
            fire = 1
            at = at + 1
        } else if (at == cyc - 35) {
            fire = 1
            at = at + 1
        } else if (at <= cyc) {
            at = at + 1
            st = 1
        } else {
            at = 0
            st = 0
        }
    }

    if (fire == 1) {
        tgt = VM_GetHomingTarget("")
        // 用标志位而不是 if (A && B)：语法上两者等价（help.md 明说支持 && ），
        // 这里只是沿用「实测跑通过」的那版写法，不打赌。
        tgt_ok = 0
        if (VM_IsUndefined(tgt) == 0) {
            if (tgt != 0 - 1) {
                tgt_ok = 1
            }
        }
        if (tgt_ok == 1) {
            ex = VM_GetProp(tgt, "x")
            ey = VM_GetProp(tgt, "y")
            es = VM_GetProp(tgt, "move_speed")
            if (VM_IsUndefined(ex)) {
                ex = 0
            }
            if (VM_IsUndefined(ey)) {
                ey = 0
            }
            if (VM_IsUndefined(es)) {
                es = 0
            }

            atk = VM_GetProp(self, "atk")
            px = ex - es * 30            // 预判 30 帧后的位置
            bx = px + 100
            by = ey - 50

            // 原版第 30 帧才结算，这里用静止子弹 30 帧内按帧等量扣完总量 atk
            VM_BulletScreenAdd("spr_zeus_bullet", 17, 2, 1.8, 0.567, bx, by, 0, 0, atk / 30, 0 - 1, 30, "all", "", "")
            // 原版是落雷第 10 帧响，这里落雷瞬间就响（差 10 帧）
            VM_PlaySound("snd_zeus")
        }
    }

    VM_SetProp(self, "attack_timer", at)
    VM_SetProp(self, "state", st)
}
